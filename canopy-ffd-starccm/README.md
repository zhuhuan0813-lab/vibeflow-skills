# 舱盖 FFD 与 STAR-CCM+ 简易教程

- **[下载运行文件 ZIP](./运行文件.zip?raw=true)**：含双击入口、注释源码与当前机身的已分区网格。
- [下载使用教程 HTML](./使用教程.html?raw=true)：下载后用浏览器打开。
- [下载代码备注 HTML](./代码备注.html?raw=true)：含文件说明和可展开的注释源码。

解压运行 ZIP，打开 `project`，双击 **开始使用.cmd**。首次按提示选择 Windows Python，再在菜单 **5** 填写 STAR 和 WSL 的软件位置。

按 **1 检查电脑 → 2 生成模型 → 3 开始气动计算** 操作，之后选 **4 查看结果**。菜单 3 会启动 STAR 并使用计算许可；菜单 1 和 2 不求解 CFD。

默认比较原始机身与 10 组舱盖方案：50 m/s、迎角 0°、+X 来流、无旋翼，宏对应 STAR-CCM+ 2510 / 20.06.007-R8。软件、Python 环境和许可由使用者准备，几何依赖见原始脚本包的 `ffd/requirements.txt`。

本包适用于其中已分区的机身；新模型需要重新分区与验证。当前网格用于方案筛选，尚未建立网格无关性。公开版调整了软件路径缺省，未更改几何、物理参数或数值算法；本次上传没有重新运行 CFD。
