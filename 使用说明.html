3 环境和路径怎么配置

最简单的做法：准备本次用到的软件，把下面的路径清单填好后发给 AI，先检查环境，再开始项目工作。不必额外创建配置文件。

① 按任务准备软件

要做的工作需要准备什么
阅读说明、整理分析流程AI 工具和本技能包即可；不需要启动求解器。
运行 Python 脚本可运行的 Python 3 环境；依赖按实际脚本或项目的 requirements.txt 安装。优先复用已有环境。
OpenVSP 建模／VSPAERO 分析相应的 OpenVSP 发行包及命令行程序。Python API 仅在脚本确实调用它时需要，并须匹配该发行包要求的 Python 版本。
STAR-CCM+ 仿真已安装的 STAR-CCM+、可用计算许可，以及与软件版本兼容的模板／Java 宏。
ParaView 后处理只有使用 ParaView 脚本时才需要 ParaView／pvpython；仅生成 Python 图表时按相应脚本准备依赖。

只准备本次任务需要的工具。本包提供流程指引，不包含工程软件、FFD 程序、机身模型或仿真结果；已有程序和项目输入需要另行提供。

② 填写这份路径清单

在软件安装目录找到对应的启动文件，复制其完整地址。软件路径填写到文件，项目路径填写到文件夹。把下面的尖括号内容换成自己的实际值，不用的项目写“未使用”。

运行位置：<Windows 本地 / WSL / Linux 服务器，说明各工具在哪边运行>
项目文件夹：<PROJECT_ROOT>
模型或算例文件：<MODEL_OR_CASE_FILE>
Python：<PYTHON_EXE；OpenVSP API 若使用另一环境，请另行注明>
OpenVSP 脚本程序：<VSPSCRIPT_EXE>
VSPAERO：<VSPAERO_EXE>
STAR-CCM+：<STARCCM_STARTER>
ParaView Python：<PVPYTHON_EXE，未使用可不填>
已有模板／脚本：<TEMPLATE_OR_SCRIPT，按需填写>
软件版本：<已知版本；未知时请 AI 检查>
  • Python：填写实际环境里的 python.exe 或 python；不要只填环境文件夹。
  • OpenVSP：采用命令行脚本方式时提供 vspscript.exe／vspscript；采用 Python API 时提供兼容的 Python 环境；运行气动求解还需 vspaero.exe／vspaero。
  • STAR-CCM+：填写本机可用的 starccm+.bat／starccm+ 启动程序，不能只填安装根目录。
  • Windows 与 WSL：同一文件在 Windows 中可能写作 <盘符>:\<目录>，在 WSL 中对应 /mnt/<小写盘符>/<目录>。Python 包要装在实际执行脚本的那个环境里；Windows 程序的调用方式需单独验证。

清单可以直接发到项目对话里。经常使用时，也可保存在自己项目的 AGENTS.md 中作为本机路径记录，不需要修改两个技能的原文。

③ 让 AI 先验证

这是我的软件路径清单（粘贴上面的内容）。
请按本次任务检查：路径是否存在、Python 是否可执行、所需模块能否导入、求解器版本是否匹配。
先报告哪些可用、哪些缺失，以及需要修改的路径；不要启动正式求解。
若缺少依赖，请按实际脚本列出安装到哪个环境的命令。

路径存在，只说明找到了文件；还要分别检查启动、模块导入与实际运行。首次正式使用时验证一个小算例，才能判断许可、模板和结果导出是否可用。

需要手动检查时：Windows PowerShell 命令

先将占位符换成实际路径，只保留本次使用的工具。以下是当前 PowerShell 会话中的临时变量，用于手动检查，不会修改系统设置，也不会自动配置已经打开的 AI 应用。

$taskPython = '<PYTHON_EXE>'
$taskVspScript = '<VSPSCRIPT_EXE>'
$taskVspaero = '<VSPAERO_EXE>'
$taskStarccm = '<STARCCM_STARTER>'

# 检查本次配置的启动文件是否存在
Test-Path -LiteralPath $taskPython
Test-Path -LiteralPath $taskVspScript
Test-Path -LiteralPath $taskVspaero
Test-Path -LiteralPath $taskStarccm

# 确认实际运行的是哪个 Python
& $taskPython -c "import sys; print(sys.executable); print(sys.version)"

# 仅读取 STAR-CCM+ 版本，不加载或求解算例
& $taskStarccm -version

这里只验证程序路径和版本。正式运行时，由 AI 把路径传给相应脚本，或按脚本支持的配置方式设置。路径含空格时保留引号，PowerShell 用 & 调用程序。

5 常见问题怎么处理

遇到的情况先检查这里
AI 没有识别技能确认打开了正确项目，两个技能各自保留 SKILL.md，目录层级与第 2 节一致；再重新打开会话。
找不到程序／路径返回 False检查是否填到了实际启动文件、文件是否搬迁，以及当前运行位置是 Windows 还是 WSL。
Python 提示缺少模块先确认 sys.executable 输出，再给同一个解释器安装实际缺失的依赖；不要只凭环境名称判断。
STAR-CCM+ 版本可读但无法计算根据启动日志检查许可、模板版本和 Java 宏兼容性；版本检查通过不代表计算已通过。

本简版只保留两个主技能。遇到其他技能引用时按当前任务补充；接收者首次使用应先检查环境并验证一个小算例。
